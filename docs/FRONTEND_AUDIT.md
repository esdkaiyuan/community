## 二、逐项详情

### 1. 「编辑项目」嵌在收藏按钮里（P0）

**症状**：个人中心「我发布的项目」卡片上，点铅笔图标进入编辑页的同时，收藏状态也被翻转一次——用户以为自己只是去改标题。

**根因**：`<router-link>` 被写在 `<button>` 标签内部。这是非法 HTML 嵌套（交互元素不能互相包含），且 click 会冒泡到 button 上的 `@click.prevent.stop`，两个动作各自生效。

**修复**：把编辑链接移到与收藏按钮**平级**（`<article>` 的直接子元素），保持 DOM 顺序仍在收藏按钮之后，既有断言里的 `card.locator('button').first` 继续命中收藏。

**验证**：
- `「编辑项目」不是嵌在收藏按钮里的` OK
- 修复前 `收藏请求 1 次` → 修复后 `收藏请求 0 次`
- 几何：编辑按钮 425–453px、收藏按钮 461–489px，8px 间距，互不重叠且都在卡片内

### 2. 移动端横向溢出（P0）

**症状**：390px 宽度下首页 / 详情页 / 个人中心全部多出 27px 横向滚动；320px 更糟。

**根因**：导航栏右侧操作区写死 `shrink-0`，且用户名 `max-w-[6rem]` 全额占位。窄屏下「发布」+ 通知铃铛 + 头像 + 用户名 + 箭头加起来超过可视宽度，整个右簇被推到视口外（实测 `right = 413 > 390`）。**溢出宽度随用户名长度变化**，所以不是固定的 27px，用户改个名字就变样。

**修复**：
- 右簇 `shrink-0` → `min-w-0`（允许收缩），发布按钮 / 铃铛 / 用户菜单各自 `shrink-0` 保住自身完整
- 窄屏只留头像：用户名与下拉箭头从 `sm`（640px）起才显示
- 顺带修掉同类隐患：窄屏点铃铛不再弹 320px 通知浮层（锚在靠右的铃铛上会从视口**左侧**溢出），直接进 `/notifications` 完整列表

**验证**：320 / 360 / 390 / 834 / 1440 五档 × 首页 / 详情 / 个人中心 = 15 组全部 `无横向溢出（多出 0px）`；`窄屏用户名收起、只留头像`、`宽屏用户名照常显示` 同时成立（没有为了修窄屏把桌面砍掉）。

### 3. 深色主题的浅色硬编码（P1）

**症状**：深色模式下鼠标划过评论区的「点赞 / 删除」，按钮底色变成 `rgb(251,233,235)`——接近白的浅粉，在纯黑页面上非常刺眼。

**根因**：全站主题靠 `style.css` 里的 CSS 变量（`--c-clay` 等）随 `prefers-color-scheme` 切换，但 `#FBE9EB` 是写死的 hex，不参与切换。

**修复**：改为令牌写法 `hover:bg-clay/10`。浅色下实际渲染色为 `rgba(215,0,21,0.1)`，与原来的 `#FBE9EB` 几乎一致；深色下自动变成 `rgba(255,69,58,0.1)`。

**验证**：断言不再用「是不是深色」这种模糊判断，而是把实测底色与 `--c-clay` 变量在**两种主题下**分别比对，能钉死到具体令牌：

```
OK  浅色下点赞悬停底色取自 --c-clay 令牌（rgba(215, 0, 21, 0.1)）
OK  深色下点赞悬停底色取自 --c-clay 令牌（rgba(255, 69, 58, 0.1)）
```

### 4. 占位色板重复实现（P2）

`utils/placeholder.js` 的注释写着「卡片封面与相关推荐封面共用，改这里两边一起生效」，但 `ProjectDetailView.vue` 自己又抄了一份 `PALETTES`。一旦两边色值分叉，同一个项目在广场和详情页会显示**不同颜色的封面**。

修复：详情页改为 `import { coverPalette }`，并加断言「卡片占位配色与详情页一致（同 id 同色板）」防止再分叉。

### 5. 卡片缺少相对时间（P2）

`docs/PROJECT_SUMMARY.md` 的卡片要素清单里明确列了「相对时间显示」，实际从未实现。列表接口本来就返回 `createdAt`，无需后端改动。

修复：作者名后追加 `· 3 天前`（`text-[11px] text-ink-dim`，无数据时整段不渲染，不留孤立的分隔符）。

### 6. 未纳入令牌的 Apple 系统色（P3，有意保留）

`#FF3B30`（顶栏未读徽标、已点赞心形）、`#34C759`（成功提示图标）是**实心强调色**，浅色深色下对比度都够，也未出现第 3 类问题里的「底色漂移」。本轮不动，记录在案：若将来要做主题换肤，需要补 `--c-rose` / `--c-green` 两个令牌。
